# 交付检查

- 真实地点已查看实拍；不能确认的细部如实标明，不冒充测绘。
- 栏目和标题逐字核对；有歧义先确认，正式图无样张、待核验提示。
- 四格关注点不同，纸纹不是细节；完整形体没有被裁断。
- 插图比例适合图框：无拉伸、无额外空白边，裁切后主体仍处于要求的位置。
- 检查插图内部留白和版面空隙分别是否合理。
- 低饱和秋色、冷纸底、印刷颗粒统一；没有明显拼接或透明白边。
- 放大查看字形、线条、边缘与位图清晰度，缩小查看整组层级与主题差异。
- SVG 的文字与图像独立可编辑，嵌入素材完整；PNG从目标尺寸直接渲染。
- 只保留用户要求的最终版本；每张图素材集中，旧候选归档在公开包外。
- 运行本地校验并实际测试导出；确认不含用户名路径、密钥、无权分发照片或字体。
- 更新SHA256，记录真实完成的检查；自动校验不证明版权或每栋建筑绝对准确。
