# STYLE_SPEC｜视觉系统详细规范

## 1. 核心视觉命题

“金陵秋日”不是暖黄色滤镜，也不是古风旅游海报。

视觉冲突来自两组感觉：

- **冷**：南京突然降温后的空气、雾蓝天色、石墙、湖水、旧纸。
- **暖**：桂花香、银杏金、梧桐黄、红枫、落羽杉锈红。

因此画面应该是：
**冷底 + 暖点；旧纸 + 鲜活季节；克制 + 明确地点识别。**

## 2. 版画处理

建议模拟：
- 木刻
- 石版
- 双色/三色套印
- 轻微错版
- 不均匀着墨
- 纸纤维吸墨

不要模拟：
- 油画厚涂
- 水彩大面积晕染
- 漫画线稿
- 3D 插画
- 摄影后期滤镜

## 3. 视觉层级

### A 层：地点/意象识别
最大、最清楚。

### B 层：秋季状态
落叶、变色、花期、倒影、枯枝、斜光。

### C 层：版画质感
只负责统一，不允许盖过 A/B 层。

### D 层：装饰性小元素
极少量使用。不得反客为主。

## 4. 构图比例

- 纯成品图：主体占 30%–55%
- 风格提案板：主视觉约占版面 50%–56%
- 留白比例服从图像用途；枝条式纯插画可参考45%–70%，城市天际线与多栏提案卡不套用此比例，避免标题旁形成无意的大空隙。
- 小元素不超过总视觉面积 8%
- 背景建筑若不是主题，不超过主体视觉权重的 50%

## 5. 色彩比例

推荐：
- 冷白 / 雾蓝 / 靛蓝：65%–80%
- 地点辅助色：10%–20%
- 秋季强调色：8%–18%

红枫、落羽杉等强色主题可以提高强调色比例，但依旧保留冷灰纸底。

## 6. 边缘处理

正确：
- 干涩
- 破碎
- 局部缺墨
- 有块面
- 不完全连续

错误：
- 统一描边
- 矢量般平滑
- 超清锐利边缘
- 发光轮廓

## 7. 文案排版

如需要文字：
- 标题短，2–8 字最好。
- 不写长段鸡汤。
- 字色以靛青、墨蓝、深灰为主。
- 字体气质偏宋体、明朝体、旧书刊标题，不做毛笔书法主视觉。
- 红印可作为极小点缀，但不是每张都必须出现。

## 8. 系列性判断

把七张图缩小并排时：
- 先感觉是一套；
- 再分别能识别七个不同主题；
- 不能出现三张以上构图几乎一样；
- 不能全部都是“树枝从右上伸进来”。
