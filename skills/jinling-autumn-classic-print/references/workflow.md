# 独立插图与本地合成

1. 确认文字、版式比例、输出目录与不得改动的部分；先看实拍和用户已认可稿。
2. 确定每个图框的尺寸和关注点，再绘制独立 PNG。提示词明确内容参考与风格参考的不同角色，写清实际地点锚点、视角、光线、低饱和色系、主体位置及禁止添加物。
3. 检查原生结果：建筑和植物、饱和度、纸纹、主体完整性、比例。不要用放大低清小裁片代替有细节的独立重绘。
4. 每张设计建立一个文件夹：`layout.svg`、`design.json`、`elements/`。示例 elements 包括纸底、主视觉与四个独立图框素材；封面收录七主题素材和玄武湖插图。
5. SVG 中用真实文本、色块和线条排版，图片为可单独替换的 image 节点。纸底是独立层，文字不烘焙进生成插图。
6. 带相对引用的 layout.svg 用于修改；交付时将 PNG 嵌入 SVG，保证单文件可携带。按目标像素直接渲染无损 PNG，保留最高尺寸，不先导小图再放大。
7. 检查最终渲染，而非只看新生成素材；确认图框未截断主体，文字不溢出，纸底和饱和度整组一致。保存采用版本与校验信息。

局部改稿先备份，再仅导出相应页；其余页可通过源稿与哈希对照确定未被改动。不要重复生成整组来改一个标题。

比例示例：本封面玄武湖素材1619×971，图框642×385，比例均约1.667，适配只需约0.011%的微小裁切；图框从左边界1030扩至852而右边不变，解决的是标题旁的空隙，不是给插图增加空白边。
