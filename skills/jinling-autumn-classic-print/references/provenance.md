# 来源、生成方式与公开发布

## 收录内容

八张终稿及其实际采用 PNG 均为本项目 AI 生成/重绘与本地 SVG 排版结果。文字、线条、色板由本地字体/矢量元素组成，素材没有被自动矢量描摹。主图与细节包含独立重绘和对新主图的局部裁切，不能将裁切说成每格均独立生成。

示例来源于2026-10-08用户确认的本地终稿，公开包复制时逐文件SHA256比对。封面为玄武湖宽幅、紫峰居中、低饱和树叶及确认的两行标题“秋天的金陵城 / 大概是这个样子的”。

|颐和路|用户提供街巷实拍|黄墙、树影、尺度；已确认主图不做测绘式声明|
|燕雀湖|用户提供湖岸照片并认可原插画|以已认可主图为准，仅调整重复细节|
|玄武湖|用户提供湖岸城市照片，画面带“SOHO PHOTOGRAPHY ©2026”署名|真实楼群、紫峰轮廓、湖岸关系；不包含原照片，不擅自转授权|

外部照片、旧风格参考图、被否定候选和本机过程日志不在公开包中。它们保留在本地归档；如果以后需要公开，维护者应先核实授权。AI重绘本身也不构成对参考权利状态的法律保证。

## 发布前由维护者决定

1. 为技能代码/文档及AI图像分别确定适合的授权范围；当前没有根 LICENSE，不宣称任何人可自由商用。
2. 确认所有参考使用、生成服务条款和最终图像的分享范围；用户确认审美不等于外部摄影授权。
3. 字体按其原许可获取；此包不分发字体。sharp 等依赖由包管理器获取，遵守其各自许可。
4. 高清示例使仓库较大，可考虑Git LFS/Release，不在未经许可时上传或迁移远端。

封面采用的最终绘图提示词见 [cover-prompt.md](cover-prompt.md)。其余示例未声称保留了全部原始生成调用；新任务可按工作流及地点锚点重绘，原位图生成具有非确定性，本地排版导出才是可重建部分。
