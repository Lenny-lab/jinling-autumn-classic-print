# 地点锚点与使用边界

每个新项目重新查看实拍，不把本示例当作精确建筑资料。

|主题|不可泛化的锚点|示例处理|
|---|---|---|
|桂花冷秋|四瓣密簇小花、椭圆叶、木质分枝|单丛花、单叶脉、枝节、整体疏密，四格不重复|
|随园银杏|扇叶、粗干、随园真实廊檐和建筑关系|红柱、米墙、青绿檐下、矩形窗、灰瓦；非泛化寺庙|
|陵园路|悬铃木高直树干、白色树基、道路标线、纵深|冷灰蓝基调，不做浓金隧道|
|栖霞山|指定门头多层檐、侧檐、柱梁、牌匾和通道|门头加红枫，不用群山替代；场景牌匾按示例用户要求随插画绘制|
|石象路|成对石象、中央石道、低篱与秋树|低饱和彩叶；形制细节完整显示象身、四足、鼻尖且上下留空|
|颐和路|黄墙、老宅窗框、行道树光影、低矮街巷尺度|不是红砖主墙；不声称逐栋测绘|
|燕雀湖|细羽状杉叶、临水树群、湖岸和倒影|杉叶与湖面细节不同焦点，保留已确认主图|
|玄武湖封面|实拍城市天际线、紫峰阶梯轮廓与尖顶、湖岸关系|约5:3宽幅、紫峰处在插图横向中央；不虚构古建填景|

“核心单字”只可用于内部构思，不要求印在画面上。若照片未显示地面，不为了银杏主题强加落叶地毯。
