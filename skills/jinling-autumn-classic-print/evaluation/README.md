# 方法验证

本目录验证的是完整 Skill 是否比普通提示词更稳定地保留地点锚点并形成统一视觉语言，不把人工闭环结果伪装成纯模型能力。

## 对照条件

- A：同一参考图 + 简单目标描述。
- B：同一参考图 + 古典版画风格描述。
- C：同一参考图 + 当前 Skill 的地点锚点、构图、色彩和负面约束。
- D：在 C 的基础上进行人工审查、筛选、局部修订和 SVG 排版。D 单独展示，不与 A/B/C 做纯模型因果比较。

A/B/C 必须使用相同参考图、生成工具、画幅、候选数和选取规则。平台无法固定随机种子时如实记录。所有候选和失败均保留在受控证据目录；未经许可的参考照片不进入公开仓库。

## 当前状态

截至 2026-10-13，实验协议和评分尺度已经建立，历史项目文件已完成基线盘点。新的 A/B/C 生成尚未完成，因此本仓库不声称 Skill 已取得量化提升。执行记录见 `cases.csv`，结论见 `results.md`。
