# 评分尺度

每项 1–5 分。评分者先看参考图和无组别标识的结果，再填写原始分数；揭盲后才能讨论方法差异。

|项目|1 分|3 分|5 分|
|---|---|---|---|
|地点锚点|核心特征缺失或被错误地标替换|保留部分特征，但关系含混|关键建筑、植物或空间关系清楚且无明显虚构替换|
|形态可信度|植物、建筑或器物存在明显结构错误|总体可辨，局部有偏差|主要形态和比例与参考证据一致|
|风格一致性|与系列色彩、纸感和线条冲突|部分一致，仍有突兀区域|冷纸、靛蓝、克制秋色和版画肌理统一|
|构图有效性|主体截断、层级混乱或无法用于目标版面|主体可用但留白或层级一般|主体完整，比例和留白适合既定图框|
|可编辑准备度|文字烘焙或素材无法分离使用|主图可用但需要较多清理|无字插画可直接进入本地 SVG 排版|

分数只能描述本批样本。少量结果不得外推为稳定的平均提升；人工修订版 D 不与 A/B/C 合并计算。
